El subjuntivo lo usamos para hablar de cosas que no hacen parte de "la realidad", pero es mejor concentrarse en la estructura.

---
# Conjugación

## Regular

|                         | -ar   | -er / -ir |
| ----------------------- | ----- | --------- |
| Yo                      | -e    | -a        |
| Tú                      | -es   | -as       |
| Usted / Ella / Él       | -e    | -a        |
| Nosotros                | -emos | -amos     |
| Ustedes / Ellas / Ellos | -en   | -an       |
## Irregulares

1. Conjugar en presente normal
	1. hacer -> hago
	2. salgo
	3. duermo
2. Eliminar la última vocal
	1. hago -> hag
	2. salg
	3. duerm
3. Añadir las terminaciones regulares
	1. haga
	2. salga
	3. duer

|                         | hacer   | salir    |     |
| ----------------------- | ------- | -------- | --- |
| Yo                      | haga    | salga    |     |
| Tú                      | hagas   | salgas   |     |
| Usted / Ella / Él       | haga    | salga    |     |
| Nosotros                | hagamos | salgamos |     |
| Ustedes / Ellas / Ellos | hagan   | salgan   |     |
| Ustedes / Ellas / Ellos | -en   | -an       |
