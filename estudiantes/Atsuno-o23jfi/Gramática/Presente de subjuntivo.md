El subjuntivo lo usamos para hablar de cosas que no hacen parte de "la realidad", pero es mejor concentrarse en la estructura.

---
# Conjugación

## Regular

|                         | -ar   | -er / -ir |
| ----------------------- | ----- | --------- |
| Yo                      | -e    | -a        |
| Tú                      | -es   | -as       |
| Usted / Ella / Él       | -e    | -a        |
| Nosotros                | -emos | -amos     |
| Ustedes / Ellas / Ellos | -en   | -an       |
## Irregulares

1. Conjugar en presente normal
	1. hacer -> hago
	2. salgo
	3. duermo
2. Eliminar la última vocal
	1. hago -> hag
	2. salg
	3. duerm
3. Añadir las terminaciones regulares
	1. haga
	2. salga
	3. duerma
4. En ==nosotros== hay excepciones

|                         | hacer   | salir    | dormir       |
| ----------------------- | ------- | -------- | ------------ |
| Yo                      | haga    | salga    | duerma       |
| Tú                      | hagas   | salgas   | duermas      |
| Usted / Ella / Él       | haga    | salga    | duerma       |
| Nosotros                | hagamos | salgamos | ==durmamos== |
| Ustedes / Ellas / Ellos | hagan   | salgan   | duerman      |
