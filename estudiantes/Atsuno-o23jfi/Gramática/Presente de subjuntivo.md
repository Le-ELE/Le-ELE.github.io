# Conjugación

## Regular

|                         | -ar   | -er / -ir |
| ----------------------- | ----- | --------- |
| Yo                      | -e    | -a        |
| Tú                      | -es   | -as       |
| Usted / Ella / Él       | -e    | -a        |
| Nosotros                | -emos | -amos     |
| Ustedes / Ellas / Ellos | -en   | -an       |
## Irregulares

1. Conjugar en presente normal
	1. hacer -> hago
	2. salgo
	3. duermo
2. Eliminar la última vocal
	1. hago -> hag
	2. salg
	3. duerm
3. Añadir las terminaciones regulares
	1. haga
	2. salga
	3. duerma
4. En ==nosotros== hay excepciones

|                         | hacer   | salir    | dormir       |
| ----------------------- | ------- | -------- | ------------ |
| Yo                      | haga    | salga    | duerma       |
| Tú                      | hagas   | salgas   | duermas      |
| Usted / Ella / Él       | haga    | salga    | duerma       |
| Nosotros                | hagamos | salgamos | ==durmamos== |
| Ustedes / Ellas / Ellos | hagan   | salgan   | duerman      |

# 1. Predicciones 1:

- Si el primer sujeto es igual al segundo sujeto y tenemos, por ejemplo, antes de o después de, usamos el infinitivo en el segundo verbo.
	- (tú) Vas a caminar después de (tú) escribir un mensaje a tu amiga.
	- (yo) Voy a caminar después de (yo) escribir un mensaje a mi amiga.
- Si el primer sujeto es diferente al segundo sujeto y tenemos, por ejemplo, antes de o después de, usamos el subjuntivo en el segundo verbo.
	- (tú) Vas a caminar después de que yo escriba a mi amiga.
